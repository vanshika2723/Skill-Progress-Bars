# 🌸 Skill Progress Bars

A cute and responsive **Skill Progress Bars** webpage created using **HTML, CSS, and JavaScript**.

This project displays technical skills with animated progress bars and percentage indicators. The progress bars smoothly animate when they come into the user's view while scrolling.

## 🎯 How It Works

Each progress bar contains a `data-progress` attribute that stores the skill percentage.

JavaScript uses the **Intersection Observer API** to detect when the progress bars enter the screen. Once visible, the bars smoothly expand to their respective percentage.

For example:

```html
<div class="progress-bar" data-progress="90"></div>
```

The JavaScript reads the value and applies it as the width of the progress bar.
